# Fact-specific source authority
Historical source https://docs.google.com/document/d/17L-A-sQILRF7mp3xHAYhFsF88AWsyz6J/edit is labeled **POLICY_ONLY_NOT_ACTIVATED**. This reference synthesizes principles and does **not** activate that policy.
| Fact class | Candidate primary authority | Mandatory scope |
|---|---|---|
| Product/catalog identity and availability of listing | governed read-only product DB | SKU/model/store/lifecycle |
| Technical specification, installation, warnings, manufacturer compatibility | approved applicable manufacturer manual/revision | model/fuel/year/config and revision |
| Approved IRG alias/crosswalk | explicitly approved mapping | owner/version/effective dates |
| Current price/promotion | live commerce pricing engine | store/customer/time |
| Inventory availability | live authorized inventory system | location/time |
| Shipping charge | live shipping/checkout engine | cart/address/time/config |
| Order/returns/warranty case state | corresponding permitted operational system | authorized record/user/time |
Applicability outranks recency. Explicit supersession outranks mere publication date. Do not silently use technical PDF to establish dynamic commercial state; do not infer installation from catalog descriptions. When authority is absent or conflicted: clarify, abstain or refer to human, never manufacture a value.
