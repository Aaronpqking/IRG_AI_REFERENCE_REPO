# Clean-lab carry-forward

Carry forward as principles: exact model/product identity; explicit document authority; fact-specific DB vs manufacturer source; canonical evidence; bounded structural parent-child context; model-visible evidence contract; sufficiency/abstention; citations; immutable evaluation. Implement only the minimum needed per measured failure.

Retest first: large graph traversal, contextualized/full views, local cross-encoder/reranking, all experimental table/owner/configuration policies and speculative automatic classifications.

Avoid: broad hardcoded manufacturer rules, duplicated evaluator/serving paths, treating candidate Recall@K as response accuracy, silently changing immutable gold, infinite view proliferation, or shipping unactivated policies as runtime claims.

Suggested build order: governed source → exact identity + lexical/dense retrieval → canonical evidence → bounded context → answerability → response and citations. Promote extras from fresh paired downstream evidence.
